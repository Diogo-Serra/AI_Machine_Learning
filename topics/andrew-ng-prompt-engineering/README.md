# Full AI Prompting Course (Andrew Ng)

Working through Andrew Ng's [**Full AI Prompting Course**](https://www.youtube.com/watch?v=8ib4Qnh2HFE) -
moving from AI novice to power user: using AI as a thinking partner for
research, writing, creativity, and building applications.

## Summary

### Module 1 - Foundations: AI basics and information retrieval

- **AI novice vs. power user** - the difference is context, iterative
  refinement, neutral questioning, and using rubrics to judge output.
- **Knowledge sources** - how AI relies on pre-trained knowledge (with a
  training cutoff) versus when it switches to live web search.
- **Web search & deep research** - when to trigger it, how to evaluate
  source reliability, and using "deep research" mode to synthesize many
  documents into a plan or report.
- **Managing context** - understanding the context window, and using
  desktop apps/file uploads to give the model better context.
- **Reasoning modes** - prompting the model to "think hard" for complex,
  multi-step reasoning tasks.

### Module 2 - AI as a thought partner: creativity and writing

- **Brainstorming** - generating creative options with iterative feedback
  loops instead of accepting the first answer.
- **Avoiding sycophancy** - framing questions neutrally to get objective,
  honest feedback rather than agreement.
- **Overcoming "AI slop"** - techniques like progressive outlining to move
  past generic, low-quality output.
- **Critiquing & editing** - incremental editing, rubrics, and cross-model
  review to raise the quality bar on writing.

### Module 3 - Beyond text: multimodal AI and application building

- **Multimodal input/output** - working with images, video, voice, and
  code, plus the cost and ethical considerations involved.
- **Images as input** - using images as context and for coarse vision
  tasks.
- **Image generation** - diffusion models and how to use them in creative
  workflows.
- **No-code app & website building** - prompting frameworks to quickly
  build functional apps and websites.
- **Data analysis** - letting AI run code, extract insights, and perform
  agentic analysis over real datasets.
- **Practical labs** - hands-on exercises building apps, games, and
  analyzing real data.

### Key takeaways

- Move from novice to power user by treating AI as a thinking partner, not
  just an answer machine.
- Use context, neutrality, rubrics, and iteration deliberately to get
  better output.
- Understand the difference between pre-trained knowledge, live web search,
  and deep research modes - and when to use each.
- Apply prompting skills beyond text: images, apps, and data analysis.
