# Machine Learning Specialization (Andrew Ng)

Working through Andrew Ng's [Machine Learning Specialization](https://www.youtube.com/playlist?list=PLkDaE6sCZn6FNC6YRfRQc_FbeQrF8BwGI)
(DeepLearning.AI / Stanford Online) - an intensive, three-course sequence
covering supervised learning, unsupervised learning, recommender systems,
reinforcement learning, and best practices for building ML models. Given the
volume of lectures, notes below are kept to a concise, course-by-course
summary rather than a video-by-video log.

## Course breakdown

### Course 1 - Supervised Machine Learning: Regression and Classification

- **Week 1** - Intro to ML, linear regression with one variable, cost
  function, gradient descent.
- **Week 2** - Multiple linear regression, vectorization, feature scaling,
  learning rate selection, feature engineering, polynomial regression.
- **Week 3** - Classification, logistic regression, decision boundaries,
  overfitting, and regularization.

### Course 2 - Advanced Learning Algorithms

- **Week 1** - Neural networks intuition and implementation (forward
  propagation, TensorFlow/NumPy).
- **Week 2** - Neural network training, activation functions, multiclass
  classification, softmax, Adam optimizer, convolutional layers.
- **Week 3** - Advice for applying ML - bias/variance, train/dev/test
  splits, learning curves, error analysis, data augmentation.
- **Week 4** - Decision trees, tree ensembles, random forests, boosted
  trees (XGBoost).

### Course 3 - Unsupervised Learning, Recommenders, Reinforcement Learning

- **Week 1** - Clustering (k-means), anomaly detection.
- **Week 2** - Recommender systems (collaborative filtering,
  content-based filtering), principal component analysis (PCA).
- **Week 3** - Reinforcement learning - Markov decision processes,
  Q-learning, deep Q-networks.
